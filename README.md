# Hamsters Life

Браузерная стратегия в реальном времени: хомяки в скафандрах из фантиков тянут стрелку от своей планеты к чужой и захватывают её численностью. Партия 3–10 минут, глубина — за счёт родов войск, бустов, магии и боссов.

> Рабочее название; вариант для релиза — «Хомяки: Галактика Щёк».

## Состояние

| Что | Статус |
|---|---|
| Спецификация | [docs/](docs/) — идея, архитектура, план, безопасность, правила работы агентов |
| Монорепозиторий | каркас готов: pnpm, TS strict, границы пакетов, CI |
| Ядро `core` | правила этапа 1 (производство, полёты, захват, бусты) + 65 тестов |
| Клиент | дуэль 1×1 против ботов: Pixi-сцена, панель плана, жетоны флота, звук |
| Бот `@hamsters/ai` | «Боец»: резерв, групповая атака, бусты |
| Карты `@hamsters/levelgen` | симметричные арены 1×1 и 1×3 по seed + ручная карта `arena-duel` |
| Повтор | seed + версии + лента команд; запись, проверка версий и воспроизведение в тот же хэш |
| Маршруты | разовая стрелка + отдельное снабжение, резка ПКМ, скорость 0.2–2 и пауза |

Ход работ по этапам и то, что осталось, — в [docs/PROGRESS.md](docs/PROGRESS.md).

## Разработка

Требования: Node.js 24, pnpm 11.

```bash
pnpm install
pnpm verify        # типы, границы пакетов, тесты, сборка
pnpm dev:web       # клиент в браузере
pnpm test          # тесты всех пакетов
```

## Структура

```
packages/core/      правила игры: состояние, тик, полёты, бой, захват, бусты (без DOM)
packages/content/   данные баланса и схемы (JSON + zod)
packages/protocol/  типы сообщений клиент↔сервер
apps/client/        Vite + PixiJS + Solid: рендер, ввод, интерфейс
tools/              служебные скрипты (границы пакетов, симулятор баланса)
docs/               спецификация и журнал работ
```
