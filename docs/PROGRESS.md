# Журнал выполнения

Источник объёма — [ROADMAP.md](ROADMAP.md). Здесь — фактическое состояние: что сделано, что в работе, что дальше, и как продолжить другому агенту.

## Как продолжить

1. Прочитать этот файл и [DEVELOPMENT.md](DEVELOPMENT.md) (там ограничения среды).
2. Прогнать `pnpm verify` — должно быть зелёно до начала работы.
3. Взять первый незакрытый пункт ближайшего этапа, сделать **мелким фрагментом**, с тестами.
4. Записать сюда строку в «Журнал» и обновить галочки, затем коммит.
5. Правило общения: о каждом изменении спецификации или заимствовании сообщать человеку (список — в [REFERENCES.md](REFERENCES.md)).

Текущий фокус: **этап 1, «Захват» против ИИ**. Этап 0 закрыт частично — клиента ещё нет.

## Этап 1. «Захват» против ИИ

### Готово

- [x] Единицы и арифметика: milli-единицы, permille, целочисленный корень, деление с округлением.
- [x] Детерминированный PRNG (mulberry32) с seed.
- [x] Формула боя и захвата, включая «гарнизон 0» и минимум после захвата (см. IDEA.md §3.4.1).
- [x] Полёт: расстояние, время в тиках, ускорение бустом.
- [x] Состояние партии из описания карты + валидация карт.
- [x] Команды `SendFleet` (несколько планет, доли 25/50/75/100) и `ApplyBoost` (три буста) с кодами отказа.
- [x] Тик: производство, семечки, продвижение флотов, разрешение одновременных прибытий, выбывание.
- [x] Хэш состояния и тест детерминизма (одинаковая лента команд → одинаковый хэш).
- [x] 65 тестов ядра.
- [x] `packages/content`: баланс и карта `arena-duel` в JSON + строгие zod-схемы, 9 тестов (включая симметрию карты и кратность 20).
- [x] Порты ядра `ContentProvider`, `SimSource`, `Scheduler`, `Bot`; класс `Simulation` вместо россыпи функций.
- [x] Бусты хранятся записью по видам, тик собран из `TICK_SYSTEMS` — новые правила добавляются списком.
- [x] Клиент: каркас Vite + Pixi + Solid, звёздный фон, презентер с тестами (14 тестов), локальный `SimSource` с планировщиком.
